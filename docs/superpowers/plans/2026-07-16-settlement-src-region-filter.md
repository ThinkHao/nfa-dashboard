# Settlement Source Region Filter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist `src_region` as a settlement snapshot and support optional source-region filtering throughout the school settlement query page.

**Architecture:** Add nullable snapshot columns through one guarded migration, propagate them through settlement generation and aggregation, and filter the snapshot columns without runtime joins. Extend the shared query parameter builder and existing APIs so all optional filters remain independently composable.

**Tech Stack:** Go, Gin, GORM, MySQL 8, Vue 3, TypeScript, Vitest, Element Plus.
